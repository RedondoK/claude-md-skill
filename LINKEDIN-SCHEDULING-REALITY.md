# LinkedIn Scheduling Reality Check

## The Confusion: Posts vs Articles

LinkedIn has **two different publishing formats**, and only one can be scheduled:

### ✅ LinkedIn POSTS (Can Schedule)

**What they are:**
- Short-form content in the "Start a post" box on your feed
- Text, images, videos (1,300 character limit)
- Shows up in news feed immediately

**Scheduling:**
- ✅ Native scheduling available (click clock icon)
- ✅ Third-party tools work (Buffer, Hootsuite, etc.)
- ✅ Can schedule 1 hour to 3 months ahead

**Use for:**
- Announcements
- Quick updates
- Sharing links with commentary

### ❌ LinkedIn ARTICLES (CANNOT Schedule)

**What they are:**
- Long-form content via "Write article" button
- Your document (this is what you're creating)
- Shows as separate article on your profile
- No character limit
- Rich formatting options

**Scheduling:**
- ❌ NO native scheduling
- ❌ NO third-party tool support
- ❌ LinkedIn's API doesn't allow it

**Source confirmation:**
LinkedIn's API does not allow scheduling tools to schedule Articles, only regular posts are supported.

LinkedIn allows native scheduling for text, image, and video posts, but polls, events, and articles cannot be scheduled using the native tool.

## The Markdown Problem

### Why Your Markdown Shows Raw

LinkedIn's Article editor **does NOT support markdown syntax**.

**What you're seeing:**
```
## Heading
**bold text**
- list item
```

**Instead of formatted headings, bold, lists.**

### LinkedIn's Limited Format Support

LinkedIn Articles use a WYSIWYG editor that understands:

**What converts automatically:**
- **Nothing from raw markdown paste**

**What LinkedIn's editor HAS:**
- Bold button (Ctrl+B)
- Italic button (Ctrl+I)
- Heading dropdown (select "Heading 1", "Heading 2")
- Bullet list button
- Numbered list button
- Link button

**What LinkedIn DOESN'T have:**
- Code blocks
- Inline code
- Tables
- Full markdown syntax
