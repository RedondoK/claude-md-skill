## Formatting Cheat Sheet

**Quick actions in LinkedIn editor:**

- **Heading:** Highlight text → Dropdown menu → "Heading 2"
- **Bold:** Highlight text → B button (or Ctrl+B)
- **Bullets:** Highlight lines → Bullet button
- **Numbers:** Highlight lines → Number button
- **Links:** Highlight text → Link button → Paste URL

**All buttons visible at top of LinkedIn editor**
